# CruxFinder 기능 명세서

클라이밍 루트 분석 및 베타 솔루션 생성 앱

---

## 1. 회원 기능

| 기능 | 세부 기능 | 설명 | 상태 |
|------|----------|------|------|
| 이메일 가입 | 이메일 인증 | 인증 코드 발송 및 중복 검사 | ✅ |
| | 비밀번호 | 영문 + 숫자 조합 규칙 | ✅ |
| | 닉네임 | 중복 검사 | ✅ |
| 로그인 | 로그인 처리 | 비밀번호 유효성 검사 및 DB 체크 | ✅ |
| | 세션 관리 | JWT 토큰 기반 세션 | ✅ |
| 비밀번호 재설정 | 이메일 인증 | 코드 발송 → 인증 → 새 비밀번호 설정 | ✅ |
| 마이페이지 | 개인정보 수정 | 닉네임, 비밀번호 수정 | ✅ |
| | 신체 정보 | 키, 체중, 암리치 입력 | ✅ |
| | 로그아웃 | JWT 토큰 제거 | ✅ |

## 2. 이미지 분석

|------|----------|------|------|
| 이미지 업로드 | 이미지 저장 | 갤러리/카메라 선택 후 서버 저장 | ✅ |
